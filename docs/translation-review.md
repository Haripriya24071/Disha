## Translation Guidelines Followed

1. **The 65-Year-Old Rule**: If an elder pauses or hesitates when reading a sentence, rewrite it using simpler everyday words.
2. **Untranslated Railway Constants**: Never translate acronyms and numbers:
   - `PNR`, `IRCTC`, `139`, `GNWL`, `RLWL`, `PQWL`
   - Platform numbers (e.g., "Platform 6")
3. **No Speculative Language**: Strict prohibition of terms like "likely to confirm" or "percent chance".
4. **Key Parity**: 100% identical key structure across all 8 files (`en`, `kn`, `hi`, `ta`, `te`, `ml`, `bn`, `mr`) to prevent runtime fallback errors.
